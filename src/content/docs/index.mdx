## What is kumolo?

kumolo runs as a standalone server that accepts standard AWS SDK v2 requests.
No mocking, no stubs — designed to behave like real AWS.

> **Goal: if it works on kumolo, it works on real AWS — and vice versa.**

  <Card title="Drop-in compatible" icon="approve-check">

## Already using AWS SDK v2?

Just point your client at kumolo — no other code changes needed.

<Tabs>
  <TabItem label="Go">
    ```go
    client := s3.NewFromConfig(cfg, func(o *s3.Options) {
        o.BaseEndpoint = aws.String("http://localhost:5566")
        o.UsePathStyle = true
    })
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import boto3

    s3 = boto3.client(
        "s3",
        endpoint_url="http://localhost:5566",
        aws_access_key_id="test",
        aws_secret_access_key="test",
        region_name="us-east-1",
    )
    ```

  </TabItem>
  <TabItem label="TypeScript">
    ```typescript
    import { S3Client } from "@aws-sdk/client-s3";

    const client = new S3Client({
        endpoint: "http://localhost:5566",
        forcePathStyle: true,
        region: "us-east-1",
        credentials: {
            accessKeyId: "test",
            secretAccessKey: "test",
        },
    });
    ```

  </TabItem>
</Tabs>

The same pattern applies to all other services — omit `UsePathStyle` and set only `BaseEndpoint`.

## Quick Start

```bash

```
